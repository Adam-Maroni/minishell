char* ft_spaced_redirection_character ( char *  command)

This function ensure that between every redirection characters a space is present by inserting one. This is necessary if we want the subcommand to be split correctly. Example cat hola>tmp.txt becomes cat hola > tmp.txt.

Parameters
commandA string from which the redirection character must be separated.
Returns
A new string, identical to command except that it does include space between each redirection character.
